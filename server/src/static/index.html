Data — import recipes, export backups, download the database.

Import from URL

Works best with sites that publish Schema.org recipe data (JSON-LD). Servings, batch yield, and ingredient amounts are stored so you can scale batches after import.

Import from file

Larder bundle JSON (full round-trip) or legacy recipe array. Servings, yield qty/unit, and ingredient quantities come through so recipes can be batch-scaled.

Export

Full JSON includes recipes, ingredient master, tags, costs, and per-store prices. Filter by tag (e.g. work) or cookbook to build a work-only deploy bundle.

Database backup

Download a copy of the SQLite database (all recipes, users, costs).
